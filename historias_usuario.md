## Historia 1
Como usuario, quiero ingresar la marca del vehículo para registrar correctamente la información.

### Criterio de aceptación
El sistema debe solicitar la marca y mostrarla en pantalla.

## Historia 2
Como usuario, quiero ingresar el modelo del vehículo para identificar el producto ingresado.

### Criterio de aceptación
El sistema debe solicitar el modelo y mostrarlo correctamente.

## Historia 3
Como usuario, quiero ingresar la cilindrada del vehículo para guardar una característica técnica.

### Criterio de aceptación
El sistema debe aceptar un valor numérico entero y mostrarlo en pantalla.

## Historia 4
Como usuario, quiero ingresar el tipo de combustible para completar los datos del vehículo.

### Criterio de aceptación
El sistema debe solicitar un texto y mostrarlo correctamente.

## Historia 5
Como usuario, quiero ingresar la capacidad en pasajeros para conocer cuántas personas transporta el vehículo.

### Criterio de aceptación
El sistema debe mostrar la cantidad ingresada por el usuario.
