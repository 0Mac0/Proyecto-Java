# Documentación del proceso

## 1. Creación del código fuente
Se creó el archivo `VehiculoApp.java` utilizando un editor de texto simple, sin el uso de una herramienta IDE. En este archivo se desarrolló un programa que solicita datos de un vehículo al usuario mediante teclado.

## 2. Uso de variables
Se utilizaron variables de tipo `String` para datos de texto (marca, modelo, tipo de combustible) y variables de tipo `int` para datos numéricos (cilindrada y capacidad de pasajeros).

## 3. Entrada de datos
Para capturar los datos ingresados por el usuario, se utilizó la clase `Scanner` junto con `System.in`.

## 4. Salida de datos
Para mostrar los resultados en pantalla, se utilizó `System.out.println()`, permitiendo visualizar los datos ingresados.

## 5. Compilación del programa
El programa fue compilado mediante la línea de comandos utilizando el siguiente comando:
`javac VehiculoApp.java`

## 6. Ejecucion
Con el siguiente comando se ejecuto el flujo como tal:
`java VehiculoApp`
